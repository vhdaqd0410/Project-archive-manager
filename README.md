# 项目档案管理器

Windows 桌面工具，用于管理项目档案从本地交付到 NAS 的完整流程。

## 技术栈

- **后端**：Node.js + Express
- **前端**：原生 HTML/CSS/JavaScript（无框架）
- **数据**：JSON 文件持久化（`data/` 目录）
- **端口**：37890

## 快速开始

```bash
# 双击运行
启动.bat

# 或命令行
node server.js
```

浏览器自动打开 `http://localhost:37890`。

## 功能

### 项目管理
- 新建 / 编辑 / 删除项目
- 搜索项目
- 状态分组：进行中 / 已完成
- 批量导入（自动扫描本地文件夹 + 部门模板管理）

### 项目归档资料交付
- 输入关键字自动检测本地和 NAS 子目录
- 文件对比（本地有、NAS 无 → 待交付）
- 勾选文件 → 一键复制到 NAS

### 上映单集版 · 修改交付
- 自动检测"上映单集版"目录
- 列出各组修改批次，标注已交付/待交付
- 勾选批次 → 整个文件夹复制到 NAS

### 000交付
- 自动检测"000交付"目录
- 列出于文件夹，标注已交付/待交付
- 勾选 → 复制到 NAS

### 其他
- 打开本地/NAS 目录（调用资源管理器）
- 复制 NAS 路径到剪贴板
- 复制交付通知信息

## 路径输入说明

**手动粘贴**：在资源管理器地址栏点击 → `Ctrl+C` → 回到工具粘贴。
不提供"浏览"按钮，避免跨进程编码问题。

## 项目结构

```
├── server.js              # 入口，启动 Express 服务
├── 启动.bat               # 双击启动脚本
├── public/
│   ├── index.html         # 前端页面（内联 CSS）
│   └── js/
│       └── app.js         # 前端逻辑
├── src/
│   ├── routes/
│   │   └── api.js         # API 路由
│   └── services/
│       ├── projectService.js  # 项目数据读写
│       ├── fileService.js     # 文件操作
│       └── importService.js   # 批量导入
├── data/                  # 运行时数据目录（自动创建）
│   ├── projects.json      # 项目数据
│   └── settings.json      # 设置
└── winforms-app/          # C# WinForms 替代方案（调试用）
```

## 依赖

仅 `express`。已在 `package.json` 中声明，`npm install` 即可。
