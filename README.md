# 项目档案管理器

视频剪辑项目档案交付 NAS 管理工具，一站式完成从本地剪辑到 NAS 交付的完整流程。

## 环境要求

- **Windows** 10/11
- **Node.js** 18+（[下载安装](https://nodejs.org/)）
- **ffmpeg**（可选，用于视频质检读取时长/编码/分辨率）

## 快速开始

### 浏览器版（轻量）
```bash
npm install
双击 启动.bat
```

### 桌面版（推荐，更稳定）
```bash
npm install
双击 启动桌面版.vbs
```

浏览器自动打开 `http://localhost:37890`（桌面版自带窗口，无需浏览器）。

## ✨ 功能

### 项目管理
- 新建 / 编辑 / 删除项目，关联本地与 NAS 路径
- **⚡ 快速创建**：选部门（AI漫剧一部/二部/九部）+ 输项目名自动拼接本地和 NAS 路径
- 项目备注、状态快速切换（🔵 剪辑中 / 🟠 修改中 / ✅ 已完成）
- 侧边栏按状态分组，已完成默认折叠
- **📌 项目置顶**：常用项目置顶显示
- **📋 项目克隆**：基于现有项目一键复制配置
- 右键菜单：编辑、设置目标集数、打开目录、复制路径等
- **最近操作栏**：左侧显示最近 5 个操作过的项目，一键跳回

### 三种交付模式

| 模式 | 说明 |
|---|---|
| **初版交付** | 扫描关键词目录，本地有 NAS 无的文件一键批量复制 |
| **修改交付** | 上映单集版按日期批次目录整体复制 |
| **000 交付** | 复制完成自动标记「已完成」，移入已完成分组 |

### 📊 集数监控（v2.5.0）

| 功能 | 说明 |
|---|---|
| **目标设定** | 右键 / 卡片按钮 / 行内输入框 / **粘贴批量导入** 四种方式 |
| **粘贴导入** | 直接粘贴 `杨永芳：1-2，69-70` 格式文本，一键解析人员和集数 |
| **自动识别总集数** | 添加人员后自动从区间提取最大集数，无需手动填写 |
| **人员缺失追踪** | 按剪辑人员分组，显示每人缺少的集数区间 + 独立进度条 |
| **缺失提示** | 智能从文件名提取集号，列出缺少区间（如 `45-47`） |
| **自动轮询** | 每 5 秒自动刷新（达标后自动停止） |
| **达标通知** | Windows 桌面通知 + Toast + 日志 |

### 🚀 交付监控与自动化

| 功能 | 说明 |
|---|---|
| **交付监控** | 「剪辑中」项目达到目标集数时桌面通知提醒，一键完成交付并自动复制目录 |
| **停滞提醒** | 项目卡在「剪辑中」3 天无更新时桌面通知，避免遗忘 |
| **NAS 对账** | 一键扫描本地与 NAS 文件差异（待交付/大小不同/时间不同/NAS 多余） |
| **质检** | 交付前检查文件大小、视频时长、编码分辨率，防止误交付半成品 |
| **快速复制** | 待交付区「⚡ 全部复制」按钮，省去勾选步骤 |

### 📊 统计与可视化

| 功能 | 说明 |
|---|---|
| **月度统计** | 按月展示项目数、交付文件数、剪辑师产出，支持导出 Excel |
| **剪辑师工作台** | 👥 按剪辑师分组展示负责项目、集数、完成率 |
| **看板视图** | 🗂️ 三列看板（剪辑中/修改中/已完成），拖拽卡片切换状态 |
| **项目时间轴** | 🕐 可视化展示项目从创建到完成的全流程事件（交付/复制/审计） |
| **交付历史对比** | 📊 对比同一项目多次交付的文件差异 |
| **仪表盘** | 📊 实时统计项目数、交付数、存储空间 |

### ✅ 待办事项
- 每个项目独立 todo list（如"补字幕""调色""等审片"）
- 点击 ☑️/⬜ 切换完成状态
- 自动汇总：X 待办 / Y 已完成

### 实时进度（v2.4.0 重写）
- 右下角面板：当前文件名、百分比、进度条
- ⚡ 实时传输速率（MB/s）+ ⏱ 预计剩余时间（ETA）
- 📋 后台任务面板（左侧）：多任务一览，每个独立进度条
- 暂停 / 取消任务（已完成部分保留）
- 完成自动复制 NAS 路径到剪贴板
- 异步非阻塞复制，文件级实时进度不再卡顿
- SSE 实时推送 + 轮询双驱动，进度流畅不卡顿

### 批量管理
- 批量改状态 / 删除、批量导入、部门 NAS 模板自动匹配路径
- **模板库**：保存常用项目配置，新建项目时一键套用

### 数据安全
- **💾 自动备份**：每日自动备份 SQLite 数据库到 `data/backups/`，保留最近 7 份
- **手动备份/恢复**：设置页可随时创建备份或从历史备份恢复
- **📥 项目导出/导入**：一键导出全部项目配置 JSON，换电脑可导入恢复
- **审计日志**：记录所有项目变更操作，可追溯

### 用户体验
- 暗色主题（localStorage 持久化）
- Toast 通知 + 文件夹历史记录（最近 10 条）
- 搜索防抖（200ms）+ 标签筛选
- 原生 Shell 文件夹浏览对话框（支持网络映射盘）
- 键盘快捷键：`Ctrl+N` 新建 / `Ctrl+F` 搜索 / `F5` 刷新 / `Delete` 删除 / `Esc` 关闭
- 顶部 🟢 服务状态指示器：点击重启 / 右键关闭
- 桌面通知：交付达标、停滞提醒、任务完成

## 常见问题

**Q: 端口被占用？** 修改 `src/config.js` 中的 `server.port` 或设置环境变量 `PORT=新端口`。

**Q: 数据在哪？** `data/archive.db` 是 SQLite 数据库，每日自动备份到 `data/backups/`。

**Q: 换电脑？** 旧电脑设置页「📥 导出项目JSON」→ 新电脑「📤 导入项目JSON」选文件。数据库也可用「💾 数据库备份」手动导出。

**Q: 质检不显示视频时长？** 需安装 ffmpeg 并加入 PATH，或设置环境变量 `FFMPEG_PATH`。

**Q: 对话框没弹？** 检查任务栏。也可从资源管理器地址栏复制路径手动粘贴。

**Q: 分享同事？** 打包发送，`npm install` 后双击 `启动.bat`。
