# 项目档案管理器

项目档案交付 NAS 管理工具，帮助从本地到 NAS 的完整交付流程。

## 环境要求

- **Windows** 系统
- **Node.js** 24+（[下载安装](https://nodejs.org/)）

## 快速开始

```bash
# 1. 安装依赖（仅第一次）
npm install

# 2. 双击运行
启动.bat

# 或命令行运行
node server.js
```

浏览器自动打开 `http://localhost:37890`，端口 37890。

## 使用流程

### 1. 新建项目

点击左侧 **「+ 新建项目」** → 填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| 项目名称 | 项目编号+名称 | `1D-1_8558_闪婚后被千亿老公宠上天` |
| 本地根目录 | 本地项目根目录 | `O:\项目归档资料` |
| NAS根目录 | NAS 项目根目录 | `M:\部门1` |
| 状态 | 剪辑中 / 修改中 / 已完成 | `🔵 剪辑中` |

> 路径可手动粘贴（从资源管理器地址栏 Ctrl+C），也可以点「浏览」按钮选择。

### 2. 项目归档资料交付（初版交付）

1. 点击左侧项目
2. 顶部输入"识别关键字"（默认 `项目归档资料`），点「应用并扫描」
3. 系统自动在本地和 NAS 目录下查找含关键字的子文件夹
4. 「待交付文件」列表显示本地有、NAS 无的文件
5. 勾选文件 → 点「复制选中到NAS」→ 逐文件实时复制

### 3. 上映单集版 · 修改交付

1. 项目目录下放 `上映单集版` 文件夹，内含按日期命名的修改子文件夹
2. 点击项目后自动检测，列出各批次
3. 勾选待交付批次 →「复制选中到NAS」→ 整个文件夹复制
4. 可「打开本地/NAS」查看、「复制路径」复制批次路径

### 4. 000交付（最终交付）

1. 项目目录下放 `000交付` 文件夹
2. 系统自动检测，列出子文件夹
3. 勾选→复制到NAS
4. **复制完成后自动将项目状态改为「已完成」**

### 5. 批量管理

- 左侧项目前勾选复选框
- 出现批量操作栏：全选 / 状态下拉 / 应用 / 删除选中
- 可批量改状态、批量删除

### 6. 批量导入

- 点「批量导入」→ 输入本地根目录
- 可配置部门 NAS 模板（自动匹配 NAS 路径）
- 点「扫描子文件夹」→ 勾选要导入的 →「导入选中」

## 交付通知

复制 NAS 路径后，点击「复制交付信息」一键生成：

```

路径：M:\部门1\项目归档资料 (共 5 个)

```

## 项目结构

```
├── server.js              # Express 服务入口
├── 启动.bat               # 双击启动
├── package.json           # 依赖（仅 express）
├── public/
│   ├── index.html         # 前端页面
│   └── js/app.js          # 前端逻辑
├── src/
│   ├── routes/api.js      # API 路由
│   └── services/          # 数据/文件服务
├── data/                  # 数据目录（自动创建）
│   ├── projects.json
│   └── settings.json
```

## 常见问题

**Q: 端口被占用？**
修改 `server.js` 中 `PORT = 37890` 为其他端口。

**Q: 数据在哪里？**
`data/projects.json` 和 `data/settings.json`，备份这两个文件即可迁移数据。

**Q: 如何分享给同事？**
整个文件夹打包发送，同事执行 `npm install` 后双击 `启动.bat` 即可。
