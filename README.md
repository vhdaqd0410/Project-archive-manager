# 项目档案管理器

项目档案交付 NAS 管理工具，一站式完成从本地剪辑到 NAS 交付的完整流程。

## 环境要求

- **Windows** 10/11
- **Node.js** 18+（[下载安装](https://nodejs.org/)）

## 快速开始

```bash
# 1. 安装依赖（仅第一次）
npm install

# 2. 双击运行
启动.bat
```

浏览器自动打开 `http://localhost:37890`。

---

## ✨ 功能

### 项目管理
- 新建 / 编辑 / 删除项目，关联本地与 NAS 路径
- 项目备注、状态快速切换（🔵 剪辑中 / 🟠 修改中 / ✅ 已完成）
- 侧边栏按状态分组，已完成默认折叠

### 三种交付模式

| 模式 | 说明 |
|---|---|
| **初版交付** | 扫描关键词目录，本地有 NAS 无的文件一键批量复制 |
| **修改交付** | 上映单集版按日期批次目录整体复制 |
| **000 交付** | 复制完成自动标记「已完成」，移入已完成分组 |

### 实时进度
- 右下角面板：百分比、当前项目名/文件名、速率估算
- 暂停 / 取消任务（已完成部分保留）
- 切换项目任务继续后台，顶部 ⏳ 指示器恢复查看
- 完成自动复制 NAS 路径到剪贴板

### 批量管理
- 批量改状态 / 删除、批量导入、部门 NAS 模板自动匹配路径

### 用户体验
- 暗色主题（localStorage 持久化）
- Toast 通知 + 文件夹历史记录（最近 10 条）
- 原生 Shell 文件夹浏览对话框（支持网络映射盘）
- 键盘快捷键：`Ctrl+N` 新建 / `Ctrl+F` 搜索 / `F5` 刷新 / `Delete` 删除 / `Esc` 关闭
- 顶部 🟢 服务状态指示器：点击重启 / 右键关闭

### 数据管理
- 导出 / 导入 JSON 备份
- 交付历史自动记录

## 项目结构

```
├── server.js                 # Express 服务（端口 37890）
├── launch.vbs                # 静默启动 Node（无控制台窗口）
├── 启动.bat                  # 双击启动
├── package.json              # 依赖（仅 express）
├── public/
│   ├── index.html            # 前端 SPA（暗色主题、进度面板）
│   ├── css/style.css
│   └── js/app.js             # 前端核心（进度、批量、快捷键、Toast）
├── src/
│   ├── routes/api.js         # 全部 REST API（含进度 Job 系统）
│   └── services/             # 数据读写 / 文件操作 / 导入服务
├── data/                     # 自动创建
│   ├── projects.json         # 项目列表
│   ├── settings.json         # 关键词、部门模板
│   └── delivery-log.json     # 交付历史
└── winforms-app/             # C# WinForms 遗留版
```

## 常见问题

**Q: 端口被占用？** 修改 `server.js` 中 `const PORT = 37890`。

**Q: 数据在哪？** `data/` 目录下 JSON 文件。侧边栏「导出备份」一键打包全部数据。

**Q: 换电脑？** 旧电脑「导出备份」→ 新电脑「导入备份」→ 选 JSON 文件。

**Q: 对话框没弹？** 检查任务栏。也可从资源管理器地址栏复制路径手动粘贴。

**Q: 分享同事？** 打包发送，`npm install` 后双击 `启动.bat`。
